# ☕ Brew Haven

**Brew Haven** is a responsive, multi-page coffee shop website designed to provide a smooth and engaging browsing experience. The website includes three main pages: Home, About, and Contact, with a consistent navigation bar and footer across all pages.

## 🌟 Features

- **Multi-Page Website:** Includes Home, About, and Contact pages with working navigation links.
- **Responsive Navigation:** A hamburger menu for mobile devices with smooth opening and closing animations.
- **Contact Form Validation:** Validates user input before submission.
  - Name: Required with a minimum character length.
  - Email: Must follow a valid email format.
  - Message: Required with a minimum character length.
- **Error Messages:** Displays validation errors below individual fields.
- **Success Message:** Displays a success message when all form fields are valid.
- **Dark/Light Mode:** Allows users to switch between dark and light themes.
- **Theme Persistence:** Remembers the user's selected theme even after refreshing the page.
- **Consistent Layout:** Reusable navbar and footer across all three pages.
